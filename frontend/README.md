# Research Workbench UI

Vue 3 + TypeScript + Vite。所有列表、统计和操作均连接本地后端，页面不生成虚拟研究结果。

## 本地开发

```powershell
npm ci --cache ../.local/npm-cache --no-audit --no-fund
npm run dev
```

开发入口为 `http://127.0.0.1:5173`。Vite 将 `/api` 和 `/actuator` 转发至 `http://127.0.0.1:18081`，保留浏览器 Host 以支持后端同源检查。

```powershell
npm run typecheck
npm test
npm run build
```

`build` 同时执行 Vue/TypeScript 检查，输出 `dist/`。`test` 使用 Node 24 的内置测试器验证工作流 SSE、对话轮询与 HTTP 响应乱序时状态不会回退。项目根目录构建脚本会将产物复制至 Spring Boot 静态资源目录。

## 页面与能力

- 研究概览：真实数据库统计、进行中的任务、工作流说明。
- 项目与任务：创建项目、创建任务、项目筛选、任务搜索、启动演示运行。
- 运行记录：状态筛选、五节点工作流、任务快照、事件、取消、审批、产物下载。
- 人工审批：待处理队列与历史决定，进入运行详情检查后审批。
- 能力路线图：展示后端能力清单，明确区分当前与待接入功能。
- 研究助手：顶栏入口，宽屏右侧并排面板、窄屏抽屉；聊天界面、上下文预览和会话 API 已就绪，模型默认不连接。

采用 hash 路由，因此直接刷新运行详情无需额外服务器路由配置。运行详情使用名为 `run` 的 SSE 事件，连接异常时每 5 秒读取一次完整状态；工作空间统计每 12 秒更新一次。终态停止实时订阅。

样式使用系统字体，无外部字体、图片或 CDN 请求。界面支持小屏幕、键盘导航、原生 dialog 焦点管理和减少动态效果设置。

## 研究助手

助手状态支持 `UNCONFIGURED`、`CODEX_CLI` 和 `MODEL_API`。默认返回未配置，发送按钮禁用；仍可编辑消息、查看上下文和会话历史。已预留模型 API 与 Codex CLI 适配，未来根据后端配置选择模型。页面依据真实状态显示已配置、暂不可用或未连接，不将接口预留视为模型调用成功。

配置可用后，助手只在用户点击“发送”时提交模型调用。检测配置、查看会话历史和生成上下文预览均不触发模型。页面上下文由后端根据项目/任务/运行/节点标识组装，发送前可预览或关闭；每条已发送消息保留当时的上下文说明。引用文字仅由用户点击“引用选中文字”时读取，且必须来自主工作区，最多 2000 字。

本浏览器只持久保存助手开关和选择的会话 ID；完整会话保存在后端数据库。运行中的对话每 2.5 秒轮询，关闭侧栏不自动取消执行。一次只允许一个调用；409/429、调用失败、取消和中断都明确展示。回复通过 Vue 文本插值转义，不执行 HTML。

“转为任务草稿”会打开原有任务表单，仍需用户选择项目、编辑内容并保存。超出目标字段 4000 字限制时只带入前 4000 字并明确提示，完整回答仍保留在对话里。

当前仅供本机单用户使用。助手界面已就绪，模型连接待配置；五节点研究工作流仍为 DEMO。已有失败、中断与取消记录保持真实状态，未配置或失败时不会生成模拟回复。文献解析/RAG、真实研究计算、工作流 Agent 执行、周期调度与多人协作仍待接入。
