# 上下文研究助手 V0.2

**当前状态：界面与适配层就绪，模型暂不接入。** `ASSISTANT_PROVIDER` 默认 `disabled`。读取页面、上下文预览、创建会话不会检测 CLI 或发送模型请求；发送消息在前后端都会被拒绝。未来选择模型后再单独进行真实服务验收。

## 交互选择

默认使用可收起的右侧栏：研究对象保留在左边，对话在右边。窄屏改为抽屉。它比自由漂浮的窗口更适合持续查看节点、证据和审批记录；上下文来自业务对象，不依赖页面坐标或截图。

当前入口有三类：通用讨论、围绕当前项目／任务／运行／节点讨论、引用用户选中文字。发送前显示上下文摘要和完整预览。回答可转为需要编辑确认的任务草稿，保存仍走原有业务接口。

## 请求链路

Vue → Spring Boot 助手 API → 会话与消息数据库 → 单独后台工作线程 → AssistantProviderRouter → 选定的 AssistantGateway 适配器。

| 提供方 | 服务端配置 | 当前验证 |
| --- | --- | --- |
| disabled | 默认值 | 不执行模型检测或请求；返回 UNCONFIGURED |
| codex | ASSISTANT_PROVIDER=codex，可选 CODEX_EXECUTABLE | 本机 CLI 与协议已检查；首次实际调用失败，暂停接入 |
| model-api | ASSISTANT_PROVIDER=model-api，MODEL_API_BASE_URL、MODEL_API_MODEL、可选 MODEL_API_KEY | 通用 HTTP 适配与本地替身测试；尚未接入真实服务 |

API 适配针对兼容 OpenAI Chat Completions 格式的服务，向基础地址追加 `/chat/completions`。仅发送 system/user 文本、`model`、`stream:false`，不传工具定义、不执行工具。远程地址需 HTTPS；本机回环服务允许 HTTP。禁用 HTTP 重定向，密钥仅放请求头，不经浏览器。原始厂商错误正文不会回传到页面。

这不是任意厂商协议的万能适配；需要 Responses 或其他格式时，增加新的 AssistantGateway 实现即可，不改变任务和对话业务接口。

Codex 适配器通过 App Server 私有标准输入输出传递 JSONL，不为浏览器开放第二个端口。采用本机生成的 0.149.0 协议结构并参考 [官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)。CLI 仍是独立安装的程序，未将二进制复制或分发到项目；未来启用才复用本机登录和模型配置，不能把 CLI 检测成功视为模型连通成功。

工作台保存对话和每次发送的上下文快照；Codex 路径每次调用建立临时线程，两种路径都发送有界历史。调用在数据库事务外执行。一个请求最多 180 秒，回答最多 24000 字符，协议及 API 响应总量有限制。取消和完成使用状态比较更新，迟到的结果不能覆盖取消。启动时把遗留请求标记为 INTERRUPTED，不消耗额度重放。

## 上下文

- 页面类型、当前项目描述、任务目标。
- 当前运行的冻结目标、节点状态、近期事件、少量产物名称和哈希。
- 用户主动选择的文字，最多 2000 字符。
- 当前已实现能力与 DEMO / research_only 边界。

上下文由后端重新读取数据库并验证对象关联，最长 12000 字符。预览和发送分别取当时的业务状态；运行仍在变化时，发送时冻结的快照为实际输入。原始 PDF、文件内容、全量市场数据、数据库凭据及其他应用内容不在页面上下文内。

## 当前权限

助手是讨论入口。未来启用 Codex 路径时，关闭执行环境访问，并关闭命令、浏览器、插件、应用、Hooks、多 Agent、图片及网页搜索等工具入口。每次启动在进程／线程内抑制继承的 MCP 与技能；不会修改全局 Codex 配置。任何未开放的工具或权限请求都会终止本次回答。沙箱同时设置为只读、权限自动拒绝；没有启用绕过沙箱。CLI 升级后需要重新核对协议及能力边界。

这不能代替未来工具执行器的权限设计。未来需要独立定义每种操作的参数、允许目录、确认条件、预算、产物和撤销／重试规则。聊天文本不是审批凭据；页面内容及引用是分析材料，不能作为新的系统指令。
