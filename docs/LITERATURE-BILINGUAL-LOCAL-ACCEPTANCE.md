# 本机双向文献检索实验（2026-09-24）

## 环境与数据

- Windows Docker Desktop；应用与 PostgreSQL 18.4 在独立 Compose 容器中，页面只绑定 `127.0.0.1:18085`。
- 向量模型：`ggml-org/bge-m3-Q8_0-GGUF`，文件大小 634,553,760 字节，SHA-256 `aa473d51f451a22f0fcf39ba3330c14bed38a385712b1113440f69df4047a173`。GGUF 先按发布方哈希校验，再只读挂载到 llama.cpp CPU 服务容器；模型端口没有发布到宿主机。
- 回答模型：`Qwen/Qwen3-4B-GGUF` Q4_K_M，文件大小 2,497,280,256 字节，SHA-256 `7485fe6f11af29433bc51cab58009521f205840f5b4ae3a32fa7f92e8534fdf5`。下载后按发布方哈希校验，与向量模型放在两个独立 llama.cpp CPU 容器中；两个容器都通过健康检查，模型端口只在本项目内部网络可达。
- UBS `Interpreting Quality with Machine Learning` PDF：原文件 SHA-256 `15d2f5cc4f06376bfc0eb2c83d04ef123bf47ff55b0a959e76f0bb2860648831`，现有 PostgreSQL 文献记录有 150 个片段。另有一篇 1 个片段的中文样例，内容关于研报复现的来源文件、SHA-256 与数据可用时间。
- 升级前已导出本机 PostgreSQL 自定义格式备份，并复制应用原文件；Flyway 从 V4 升至 V5 后，两篇文献记录仍可读取。

`bge-m3` 的简短向量探针中，中英文同义句余弦相似度约 0.88；中文问题与无关天气句约 0.37。该探针只确认向量接口及基础跨语言表示，不代表真实研报的召回率。UBS 中文查询的首条命中是 PDF 物理第 4 页；所有命中仍保留原文、页码、文件哈希与片段哈希。

H2 独立实验库也导入了同一 UBS PDF，建立 151/151 个片段的索引，并通过上述双向查询。它与 PostgreSQL 中的旧文献记录是两次独立解析，因此切块数不同；正式本机页面的验证以 PostgreSQL 中的 150 个旧片段为准。

## 回答与译文实测

- 英文问题询问中文样例的来源与数据可用时间：旧版同步请求约 21.7 秒，返回 1 条证据、中英回答、英文译文，两个回答的引用编号都为 `[C1]`。改为分阶段显示后，回答与原文约 17.1 秒返回，`translationStatus=NOT_REQUESTED`；页面随后单独请求译文。
- 中文问题询问 UBS 研报中的机器学习与质量因子：旧版同步请求约 494.8 秒，返回 5 条英文证据、5 条中文译文和中英回答，两个回答的引用编号都为 `[C1]`。五条一批曾在约 137 秒后校验失败；改为最多三条一批、失败后逐条重试，最终 5/5 完成。中间试验的 3 条批次约 120.7 秒成功，拆批后的一次 5 条检索约 162.5 秒返回 3/5 译文并如实标记 `PARTIAL`。
- 当前页面和 API 已改为先返回双语回答及原文引用，再异步补充译文；译文仍可能耗时数分钟。Docker Desktop Model Runner 曾返回引擎错误及 HTTP 502，本次已验证链路使用独立 llama.cpp 容器。

## 尚待验证

这些请求只证明链路可运行，尚未证明召回率或回答事实正确。应用只检查引用编号存在、范围有效以及中英回答引用集合一致；没有逐句验证每个主张都受对应片段支持。译文也没有完成数值、否定和术语的人工核对。下一步应建立固定的中英双向问题集，统计 Recall@5、MRR、引用正确率与翻译错误，并决定是否改用 GPU 或外部 API 缩短等待时间。

## 2026-09-28 全项目检索问题复盘

本机验收项目现有四篇文献，共 257 个片段。复盘前只有 UBS 的 150 段和中文样例的 1 段已建立向量索引；两篇新导入的中文研报共 106 段未建立索引。BGE-M3 容器原来的物理批大小为 512 token，中文长片段触发 `input (647 tokens) is too large`；调至 2048 后，106 段在约 104 秒内补齐，达到 257/257。

问题 `When reproducing a research report, which three records must be retained?` 在旧融合算法下，前五条全是 UBS PDF 第 29–31 页的声明。直接对比向量相似度，中文样例约为 0.54，最接近的 UBS 声明约为 0.47；旧算法把英文关键词排名与语义排名等权合并，压低了真正相关的跨语言证据。新 `hybrid-bm25-embedding-v2` 在完整索引上只返回中文样例一条；英文译文保留了来源文件、SHA-256、数据可用时间及原文标记。双语回答分别用 `[C1]` 引用这条证据，回答请求约 13.6 秒。

另测英文 `How is the chip distribution factor constructed?`，前五条都来自中信建投中文研报；询问 UBS 的机器学习质量因子时，前五条来自 UBS 正文第 1、4、12、13 页。无关问题 `What is the weather in Paris tomorrow?` 返回零条证据，问答接口返回 `NO_EVIDENCE`。本机 BGE-M3 最低余弦阈值暂设 0.45，属于这几道问题上的实验校准，不代表通用阈值。完整译文质量还需人工逐段核查，当前本机 Qwen3 4B 不能视为研报翻译的可靠终版。

长篇 UBS 正文的五条译文测试约 150 秒，其中一条 JSON 输出为空，系统保留原文并标记 `PARTIAL`。单独重放该 C2 片段时，模型的 JSON 模式返回 `{}`，纯文本模式能生成中文译文；加入逐段纯文本回退后，对前两条的复测约 48 秒，两条均返回译文。该回退仅恢复格式失败，不证明译文完整或术语准确；PDF 提取文字中仍可见断词和页眉噪声。
